# Study

Use this skill when the next move depends on an important unknown. Inspect the real artifact and its behavior, then gather only the evidence that can change the decision. Keep study brief for familiar, reversible work.

1. State the requested result and the unknown that could change it.
2. Inspect the closest primary source: code, data, contract, behavior, or user evidence.
3. Compare the strongest plausible alternatives and failure modes.
4. Make the smallest useful probe or change, then use its result as new evidence.

Read [the detailed guide](references/guide.md) when the work is contested, high consequence, or broad enough to need an evidence map. Stop when the decisive facts are supported and remaining uncertainty is explicit.
