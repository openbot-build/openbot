# Nobody Cares How

Keep the product focused on the user's result, meaning, choices, and recovery. Move implementation detail backstage unless it is required for a safe or informed decision.

1. Identify what the user is trying to accomplish.
2. Remove jargon, internal names, and machinery that do not help that goal.
3. Preserve the facts, limits, and recovery actions the user genuinely needs.
4. Review the complete user-facing path for respectful, plain language.

Read [the detailed guide](references/guide.md) when a review spans product copy, errors, workflows, or operational feedback.
