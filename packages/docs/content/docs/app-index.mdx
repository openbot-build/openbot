The App Index is a public list of Apps. You can search it without signing in.
Your client may use the OpenBot index or another index service.

## Search and inspect

Search by the work you want to do or the App name. Read the description,
publisher, and source address. Results can be incomplete when an outside index
cannot be reached. Try again later if an expected source is missing.

## Connect a result

Choose the App you intend to use and follow [Connect and use Apps](/docs/apps).
An index result is not a connection or a grant of access. You still review the
service and sign in when needed.

## When an App is absent

The publisher may not have asked for indexing, may have withdrawn it, or the
host may restrict it. A private manual connection does not appear in the public
index. Ask the App provider for its address or your administrator about local
availability.

## Saved public checks

A public check has one shared execution. PostgreSQL keeps each result. A saved
timer starts the next check, and a command can ask for an earlier check. Several
requests may share one pending check. A server restart keeps its saved progress.

A temporary network failure keeps the last confirmed entry and schedules another
check. A confirmed withdrawal, `noindex`, or robots denial removes the entry.
Private App connections stay in place. A platform restriction still blocks use.

The data move keeps old entries, check results, and the next check time. It puts
each old Index job under the shared platform execution. An unfinished public
read may run again after startup. The data move itself sends no network request.
