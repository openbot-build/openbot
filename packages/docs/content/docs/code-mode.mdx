Code Mode lets a Bot use a short program to call App tools and work with their
results. Your platform operator must enable it. You do not need to write the
program yourself.

## Give the task

Connect the [Apps](/docs/apps) the task needs, then tell the Bot the result you
want. The Bot can choose a program when it helps handle several calls or large
results. Each call still uses the same access checks as an ordinary App call.

## Review a decision

A request can include the program and the App call that needs your decision.
Review the actual action and values. The program does not gain more access
because it contains several calls. [Vault](/docs/vaults) references also keep
their own restrictions.

## Check the result

A program can be running, waiting for a decision, complete, failed, or
cancelled. A later result returns to the Chat. If the connection changed while
it waited, the program may stop. Check the recorded calls before starting the
task again, especially when an App may already have changed data.

An upgrade keeps saved results. Old work that cannot safely continue is marked
interrupted. Reading its history does not run it again.
