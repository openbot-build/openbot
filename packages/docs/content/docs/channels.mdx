---
title: "Use a Bot in chat services"
description: "Use a Bot in chat services"
---

A Channel connects your organization to Slack, Lark, Telegram, or another chat
service. Your administrator sets it up.

## Link your account

Send the Channel bot a message. If your account is not linked, it returns a link
or code. Sign in through the client your organization provides, check the
account, and accept the link. The code lasts 15 minutes and works once. You need
active membership in that organization.

## Talk in a group

In a direct chat, send a message to the bot. In a group, name the bot in your
message. It works with the rights and App connections of the speaker. Another
speaker may wait while the current work runs. Answers and later task results
return to the chat, so consider who can read that group.

## Answer a request

The Channel can show Allow once, Allow in this chat, and Deny. Only the person
asked can decide. Read the action before choosing. Unlink a chat account you no
longer use. If linking or delivery fails, ask the administrator responsible for
the Channel.

## Recovery

A restart keeps accepted input and saved send results. If OpenBot cannot tell
whether a message went out, it pauses that send. Ask the Channel administrator
to check its execution. Sending the same message again may make a second post.
