OpenBot 通过 HTTP
API 运行 Bot。Bot 是使用模型和工具完成工作的程序。OpenBot 本身没有用户界面。你的组织提供客户端或已连接的聊天服务。

## 选择手册

| 你的任务               | 从这里开始                           | 需要什么                       |
| ---------------------- | ------------------------------------ | ------------------------------ |
| 用 Bot 完成工作        | [用户手册](/zh-cn/docs/users)        | 账户、组织及其客户端或 Channel |
| 管理人员和服务         | [管理员手册](/zh-cn/docs/admin)      | 对应组织或平台的管理权限       |
| 接入软件或修改 OpenBot | [开发者手册](/zh-cn/docs/developers) | API 访问权限或源代码           |

按当前任务选择手册。如果你自己运行服务器，可能同时承担多个角色。每本手册都有自己的起点。

## 关于这些文档

指南说明此代码库中的 OpenBot。[API 参考](/docs/api/)由 HTTP 契约生成。[执行设计](/zh-cn/docs/architecture)会说明哪些部分仍处于计划阶段。

OpenBot 使用 `AGPL-3.0-only` 许可证。完整条款见
[LICENSE](https://github.com/openbot-build/openbot/blob/main/LICENSE)。
