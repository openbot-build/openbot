本手册面向编写软件来使用或扩展 OpenBot 的开发者。API 访问不会带来额外权限。每个请求仍以调用者的身份执行。

## 接入客户端

准备已有的 OpenBot 地址和组织账户。需要测试服务器时，使用[本地 API 快速开始](/zh-cn/developers/quickstart)。

1. 实现[登录、组织选择和令牌](/zh-cn/developers/authentication)。
2. 使用 [TypeScript 客户端](/zh-cn/client)或 [HTTP 参考](/api/)。
3. 发送 [Bot 消息](/zh-cn/developers/bots)，读取
   [Chat 结果和流](/zh-cn/developers/chats)，并处理[请求](/zh-cn/developers/requests)。
4. 按客户端需求接入[文件](/zh-cn/developers/files)、[App](/zh-cn/developers/apps)或[实时会话](/zh-cn/developers/live)。

侧栏中的 API 任务指南说明请求字段、响应状态和错误。客户端负责自己的界面和返回路径。

## 发布 App

你需要控制 App 服务及其公开 HTTPS 地址。

1. 按 [App Protocol](/zh-cn/protocol)发布文档。
2. 使用[协议测试服务](/zh-cn/protocol-test)检查。
3. 通过[发布者工具](/zh-cn/developer-tools)证明控制权、测试连接并申请收录。
4. 搜索和撤回规则见 [App Index 契约](/zh-cn/developers/app-index)。

## 参与 OpenBot 开发

1. 阅读[贡献指南](/zh-cn/contributing)，了解环境、检查和项目规则。
2. 阅读[包边界](/zh-cn/packages)和[执行设计](/zh-cn/architecture)。
3. 通过[从代码运行](/zh-cn/server)组合服务端。在这里接入[模型后端](/zh-cn/developers/model-backends)、[实时后端](/zh-cn/developers/live-backend)或[日志](/zh-cn/developers/logging)。
4. 维护项目发布时，遵循[发布和检查](/zh-cn/developers/publishing)。

正式环境的安装和机密配置见[管理员手册](/zh-cn/admin)。
