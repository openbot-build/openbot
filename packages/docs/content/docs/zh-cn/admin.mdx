本手册面向管理组织或运行 OpenBot 服务的人员。OpenBot 没有管理界面。管理任务通过 API 或工具完成。这里的 API 示例属于管理操作。

## 确定职责

| 角色           | 职责                                         | 所需权限                             |
| -------------- | -------------------------------------------- | ------------------------------------ |
| 组织管理员     | 一个组织内的成员、角色、模型、预算和共享服务 | 各页说明的权限                       |
| 平台管理员     | 平台设置、共享提供方和组织策略上限           | 平台管理权限                         |
| 服务器运维人员 | 安装、升级、备份和监控服务                   | 服务器、数据库、存储和密钥的访问权限 |

组织角色不会授予平台权限。服务器访问权限与平台 API 权限也不同。任务需要另一角色时，请交给负责该职责的人。

## 管理组织

1. 阅读[组织和成员](/zh-cn/organization)及[权限](/zh-cn/permissions)。
2. 如果组织使用自己的登录服务，配置 [SSO 和域名](/zh-cn/sso)。
3. 添加[模型和提供方](/zh-cn/models)，再设置[价格和预算](/zh-cn/usage)。
4. 按需连接
   [Channel](/zh-cn/admin/channels)、[Computer 提供方](/zh-cn/admin/computer-providers)或[机密提供方](/zh-cn/admin/secret-providers)。
5. 把客户端地址和[用户手册](/zh-cn/users)交给成员。

## 运行平台

1. 阅读[部署](/zh-cn/deploy)与[实例配置](/zh-cn/configuration)。
2. 配置[平台](/zh-cn/platform)与[登录提供方](/zh-cn/admin/sign-in)。
3. 按需配置[文件存储](/zh-cn/admin/file-storage)、[实时模型](/zh-cn/admin/live-models)和
   [Code Mode](/zh-cn/admin/code-mode)。
4. 设置
   [App Index 限制](/zh-cn/admin/app-index)，并[配对你负责的机器](/zh-cn/admin/pair-computer)。
5. 按[备份步骤](/zh-cn/deploy#备份)和[错误日志](/zh-cn/error-logs)维护服务。

## 处理问题

先确定受影响的组织与账户，再检查成员资格、权限及模型是否可用。服务器故障交给运维人员处理。提供发生时间和请求 ID，便于查找日志。源码修改请使用[开发者手册](/zh-cn/developers)。
