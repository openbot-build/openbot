邀请制升级默认值、邮箱登录、审批、组角色及管理员恢复请参阅[账号准入](/zh-cn/access)。

使用组织提供的客户端地址。OpenBot 使用外部登录服务，不保存你的密码。

## 登录

在客户端开始登录。需要时填写工作邮箱，让 OpenBot 选择正确的登录服务。在该服务完成登录后返回客户端。如果没有可用的登录服务，请联系管理员。

## 选择组织

属于多个组织时，选择本次工作的组织。登录本身不会建立成员资格。你需要接受邀请，或通过管理员配置的域名或登录服务加入。暂停的成员资格不能用于工作。

直接 Chat 和 App 连接属于你在该组织中的个人空间。切换组织不会移动它们。

## 管理访问

用户令牌是让程序在一个组织内代表你工作的机密。只有所用工具需要时才创建。为令牌设置清楚的名称和到期时间。首次显示时保存机密，之后无法再次读取。工具不再需要访问时撤销令牌。令牌不能超出你的账户权限。

在共用设备上完成工作后退出登录。密码或登录恢复请通过登录服务处理。成员资格和权限问题请联系组织管理员。
