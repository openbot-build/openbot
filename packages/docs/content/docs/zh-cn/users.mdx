本手册面向让 Bot 完成工作的使用者。你需要加入 OpenBot 组织，并使用该组织的客户端或聊天服务。不同客户端的名称和操作方式可能不同。请向管理员获取地址。

## 从这里开始

1. [登录并选择组织](/zh-cn/authentication)。
2. 完成[第一个任务](/zh-cn/quickstart)。
3. 了解如何[与 Bot 交谈](/zh-cn/chats)和[回答请求](/zh-cn/requests)。

## 查找任务

| 任务                             | 指南                                              |
| -------------------------------- | ------------------------------------------------- |
| 选择或创建工作助手               | [Bot](/zh-cn/bots)                                |
| 与他人共享 Bot                   | [共享 Bot](/zh-cn/sharing)                        |
| 使用语音                         | [实时模式](/zh-cn/live)                           |
| 把文档交给 Bot                   | [文件](/zh-cn/files)                              |
| 把长任务交给助手                 | [委派](/zh-cn/delegation)                         |
| 定时运行任务                     | [触发器](/zh-cn/triggers)                         |
| 在 Slack、飞书或 Telegram 中使用 | [Channel](/zh-cn/channels)                        |
| 使用机器完成工作                 | [Computer](/zh-cn/computers)                      |
| 保留或撤销决定                   | [规则与授权](/zh-cn/rules)                        |
| 查看 Bot 记住的内容              | [记忆](/zh-cn/memory)                             |
| 查找并连接外部服务               | [App Index](/zh-cn/app-index)、[App](/zh-cn/apps) |
| 理解调用 App 的程序              | [Code Mode](/zh-cn/code-mode)                     |
| 让 Bot 使用机密                  | [Vault](/zh-cn/vaults)                            |

## 获取帮助

缺少模型、权限、存储或 Channel 时，请联系组织管理员。客户端缺少某项操作时，请联系客户端提供者。说明任务、时间和错误信息。不要在报告中放入密码或令牌。
