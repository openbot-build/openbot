本指南使用组织已经运行的 OpenBot 服务。你需要该组织的客户端或已关联的
[Channel](/zh-cn/docs/channels)、有效成员资格，以及配置了可用模型的 Bot。

## 开始对话

1. [登录](/zh-cn/docs/authentication)，选择要工作的组织。
2. 选择你可以使用的 Bot。如果没有，请向管理员申请。
3. 发送一个小任务：“列出开会前要检查的三件事。”
4. 在同一对话中阅读回答。你可以继续补充、更正或提问。

OpenBot 为你与这个 Bot 保留一个直接 Chat。客户端可以逐步显示回答，也可以在完成后显示。

## 交给 Bot 更多工作

说清想要的结果，并提供必要信息。任务需要时，添加[文件](/zh-cn/docs/files)或连接
[App](/zh-cn/docs/apps)。长任务可以通过[委派](/zh-cn/docs/delegation)稍后返回结果。

收到[请求](/zh-cn/docs/requests)时，先核对操作和授权范围，再作决定。Chat 中出现回答，不一定表示所有后台工作都已结束。

## 无法开始时

没有组织成员资格时，需要管理员邀请或授权。Bot 没有可用模型时，需要选择模型。无法选择时，请联系管理员。客户端缺少操作入口时，请联系客户端提供者。
