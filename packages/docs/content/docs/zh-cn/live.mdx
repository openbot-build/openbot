---
title: "在实时模式中使用语音"
description: "在实时模式中使用语音"
---

实时模式支持带语音的实时对话。它需要支持此模式的客户端和可用的实时模型。请向管理员确认可用模型。

## 开始会话

使用客户端的实时功能，选择可用模型，并在客户端请求时允许麦克风访问。实时 Chat 与普通直接 Chat 分开。讲话时保持连接。

## 跟进对话

通过客户端讲话或发送文字。支持的输入和操作取决于实时后端。允许工具操作前，先阅读[请求](/zh-cn/docs/requests)。实时模式不会扩大 Bot 的权限。

## 结束或重新连接

结束时通过客户端关闭实时会话。声音或连接出错时，先检查麦克风权限和网络，再按客户端说明重新连接。模型不可用时请联系管理员。缺少实时操作入口时请联系客户端提供者。

删除 Live
Chat 时，系统先停止已保存的工作，并关闭声音连接。连接释放资源后，删除命令才完成。正在建立的连接也遵循此规则。删除命令被接受后，不能再为该 Chat 建立新连接。

连接关闭失败会保留记录。重复删除不会把节点失联视为关闭成功。命令会等待已确认的释放结果。
