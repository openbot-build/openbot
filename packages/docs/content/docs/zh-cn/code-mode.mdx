Code
Mode 让 Bot 用短程序调用 App 工具并处理结果。平台运维人员需要先启用它。你不需要自己编写程序。

## 提出任务

连接任务需要的
[App](/zh-cn/docs/apps)，告诉 Bot 想要的结果。需要处理多次调用或大量结果时，Bot 可以选择使用程序。每次调用仍经过普通 App 调用所用的访问检查。

## 检查决定

请求可以包含程序，以及等待决定的 App 调用。核对实际操作和传入内容。程序不会因为包含多个调用就获得更多权限。[Vault](/zh-cn/docs/vaults)
引用也保留各自的限制。

## 查看结果

程序可能正在运行、等待决定、已完成、失败或已取消。稍后的结果会返回 Chat。等待期间连接发生变化，程序可能停止。再次启动任务前先检查调用记录，尤其要确认 App 是否已经修改了数据。

升级会保留已保存的结果。不能安全继续的旧工作会标记为中断。读取历史不会重新执行它。
