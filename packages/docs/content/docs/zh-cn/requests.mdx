title: "回答请求"
description: "回答请求"
---

请求要求对 Bot 的某项操作作出决定。只处理等待你决定的请求。它们可能出现在客户端或已关联的
[Channel](/zh-cn/docs/channels) 中。

## 核对操作

查看哪个 Bot 发起请求、要做什么、目标是什么以及理由。调用 App 时，还要核对传入的内容。Bot 的理由用于解释请求，不是你必须遵循的指令。操作不符合任务时，拒绝并说明原因。

## 选择范围

| 选择             | 作用                               |
| ---------------- | ---------------------------------- |
| 允许一次         | 允许本次调用                       |
| 在此 Chat 中允许 | 保留授权，用于此 Chat 中匹配的工作 |
| 长期允许         | 保留授权，直到撤销                 |
| 拒绝             | 不执行该调用                       |

Chat 可能持续很长时间。只想允许一次时，就选择一次。如果客户端提供相应范围，也可以在 Chat 内或长期保留拒绝决定。已保存的决定见[规则与授权](/zh-cn/docs/rules)。

一次性批准与保存的调用及其参数绑定。重启后可以恢复同一个调用，但不能把授权用于其他调用。撤销授权或新增拒绝规则仍会阻止调用。

## 查看后续结果

允许后执行调用，结果返回 Chat。拒绝后不执行。普通请求无人回答时会到期拒绝，默认等待 24 小时。计划请求有自己的到期处理方式，请先阅读，不要认为等待必然表示拒绝。请求需要他人决定时，请由该人检查。

旧版本保留的请求可能仍显示为待处理，但其执行已经中断。你可以查看它们，但不能批准旧操作。请向 Bot 发送新消息，以当前权限重新发起请求。
