---
title: "让 Bot 使用 Computer"
description: "让 Bot 使用 Computer"
---

Computer 是 Bot 用来运行命令和处理文件的机器，可以是提供方的沙箱，也可以是由运维人员配对的机器。

## 选择机器

使用你有权访问的 Computer，或申请一个。授权给 Bot 前，检查机器中的文件和服务。Computer 是访问边界：获得访问权的 Bot 可以在整台机器内工作。

## 交给 Bot 工作

说明任务和应使用的 Computer。访问机器、创建沙箱、删除沙箱或开放公开端口时，可能需要你[作出决定](/zh-cn/requests)。任何知道公开端口地址的人都可以使用该地址。

机器支持时，客户端可以显示命令、文件和桌面操作。已配对的机器离线时，需要由运维人员重新连接。

## 结束访问并检查费用

不再需要时，撤销 Bot 的访问权。删除沙箱也会删除其中的文件，请先保存结果。闲置沙箱可能暂停，自己配对的机器不会。提供方的费用独立于模型预算。模型预算不会停止 Computer。

撤销访问后，不能再通过 OpenBot 发送命令或读取输出。输入或文件修改结果未知时，重试前先检查机器。连接丢失不代表最后一次操作已经停止。

创建、暂停、恢复和删除 Computer 都使用持久执行。你可以重新连接事件流，而不再次启动动作。提供方回复丢失后，执行会保留未知结果，等待人检查。发出取消请求不代表沙箱已经停止。自动空闲暂停和恢复也遵守这些规则。
