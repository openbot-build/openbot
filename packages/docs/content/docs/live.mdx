---
title: "Use voice in Live mode"
description: "Use voice in Live mode"
---

Live mode is a real-time conversation with sound. It needs a client that
supports Live mode and an available Live model. Ask your administrator which
model you can use.

## Start a session

Use the Live function of your client, choose the available model, and allow
microphone access when the client asks. A Live Chat is separate from the normal
direct Chat. Keep its connection open while you speak.

## Follow the conversation

Speak or send text through the client. Supported input and controls depend on
the Live backend. Read [requests](/docs/requests) before allowing tool actions.
Live mode does not give the Bot more access.

## End or reconnect

End the Live session through the client when finished. If sound or the
connection fails, check microphone access and the network, then follow the
client’s reconnect steps. If the model is unavailable, ask the administrator.
Missing Live controls are a question for the client provider.

Deleting a Live Chat first stops its saved work and closes its sound connection.
The delete command finishes after the connection has released its resources.
This also applies while a connection is still opening. New connections cannot
open after the delete command is accepted.

A failed connection close stays recorded. Repeating a delete does not treat a
missing node as a successful close. The command waits for a known release.
