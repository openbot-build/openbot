A Chat is your conversation with a Bot. OpenBot keeps one direct Chat for you
and each Bot. Your client shows its messages and work.

## Give and guide work

Send the result you want, with the facts the Bot needs. Add [files](/files) when
needed. One stretch of work is a Turn. A further message from the same author
can guide the running Turn. In a group, another person may have to wait for
their own Turn.

Use plan mode when you want a plan before work starts. Check whether that plan
needs approval. A todo list records steps; it does not itself prove that work is
complete. The Bot can also set a reminder to return to a task later.

## Read the result

Your client may show a stream or a complete answer. Long
[delegations](/delegation), [requests](/requests), and reminders can bring later
messages. Check the open work as well as the last answer. Closing a stream does
not stop the work.

A long conversation may be summarized to fit the model. Give key facts again if
the Bot needs them.

## Stop or clear work

Use your client to interrupt a running Turn when you need it to stop. Check
separate background work too. Stopping work does not undo actions that already
happened in an App.

Deleting history removes the Chat history. It does not erase the separate
[Bot memory](/memory). Files kept only by that Chat can be removed later. For a
failed Turn, read the error before sending the same task again.
