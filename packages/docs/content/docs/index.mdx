OpenBot runs Bots through an HTTP API. A Bot is a program that uses a model and
tools to do work. OpenBot has no user interface of its own. Your organization
supplies a client or a connected chat service.

## Choose your manual

| Your task                          | Start here                           | What you need                                          |
| ---------------------------------- | ------------------------------------ | ------------------------------------------------------ |
| Use a Bot for your work            | [User manual](/docs/users)           | An account, an organization, and its client or Channel |
| Manage people and services         | [Administrator manual](/docs/admin)  | Rights for your organization or platform               |
| Connect software or change OpenBot | [Developer manual](/docs/developers) | API access or a copy of the source code                |

Choose by the task you are doing now. Running your own server may give you more
than one role. Each manual states its own starting point.

## About these docs

The guides describe OpenBot in this repository. The [API reference](/docs/api/)
is made from its HTTP contract. The [execution design](/docs/architecture)
states which parts of that design are still planned.
