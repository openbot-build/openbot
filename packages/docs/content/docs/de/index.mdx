OpenBot führt Bots über eine HTTP-API aus. Ein Bot ist ein Programm, das mit
einem Model und Werkzeugen arbeitet. OpenBot hat keine eigene
Benutzeroberfläche. Deine Organisation stellt einen Client oder einen
verbundenen Chat-Dienst bereit.

## Wähle dein Handbuch

| Deine Aufgabe                          | Hier beginnen                             | Was du brauchst                                            |
| -------------------------------------- | ----------------------------------------- | ---------------------------------------------------------- |
| Mit einem Bot arbeiten                 | [Benutzerhandbuch](/de/docs/users)        | Ein Konto, eine Organisation und deren Client oder Channel |
| Personen und Dienste verwalten         | [Administrationshandbuch](/de/docs/admin) | Rechte für die Organisation oder Plattform                 |
| Software verbinden oder OpenBot ändern | [Entwicklerhandbuch](/de/docs/developers) | API-Zugriff oder den Quellcode                             |

Wähle nach deiner jetzigen Aufgabe. Wenn du selbst einen Server betreibst,
kannst du mehrere Rollen haben. Jedes Handbuch nennt seinen eigenen Einstieg.

## Über diese Dokumentation

Die Anleitungen beschreiben OpenBot in diesem Repository. Die
[API-Referenz](/docs/api/) entsteht aus dem HTTP-Vertrag. Der
[Ausführungsentwurf](/de/docs/architecture) nennt die Teile, die noch geplant
sind.

OpenBot nutzt `AGPL-3.0-only`. Die Bedingungen stehen in der
[LICENSE](https://github.com/openbot-build/openbot/blob/main/LICENSE).
