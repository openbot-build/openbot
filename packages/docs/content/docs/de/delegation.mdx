---
title: "Lange Arbeit an einen Bot geben"
description: "Lange Arbeit an einen Bot geben"
---

Bei einer Delegation gibt ein Bot eine Aufgabe an sich selbst oder einen anderen
Bot. Sie läuft in einem eigenen Chat. Im ursprünglichen Chat kannst du weiter
sprechen.

## Eine klare Aufgabe geben

Nenne Ergebnis, nötige Angaben und Grenzen. Bitte den Bot, die Arbeit an einen
passenden Helfer zu geben. Ein neuer Helfer oder ein anderer Bot kann eine
[Anfrage](/de/docs/requests) brauchen. Die Aufgabe arbeitet für die Person, die
sie gestartet hat.

## Die Arbeit verfolgen

Prüfe offene Arbeit im Client. Das Ergebnis kommt in den ursprünglichen Chat
zurück. Ein Bot kann frühere Delegationen ergänzen und ihren Zusammenhang
behalten. Eine kurze Antwort kann vor dem Ergebnis der Delegation eintreffen.

## Stoppen oder fortsetzen

Bitte den Bot, eine unnötige Delegation zu stoppen, oder nutze die entsprechende
Funktion im Client. Eine Zeit- oder Tokengrenze kann die Arbeit pausieren. Prüfe
den Zustand vor dem Fortsetzen. Stoppen nimmt bereits ausgeführte externe
Handlungen nicht zurück.
