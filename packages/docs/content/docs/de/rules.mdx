description: "Regeln und Freigaben"
---

Eine Freigabe (Grant) behält eine erlaubende oder ablehnende Entscheidung für
eine Bot-Fähigkeit. Eine Regel beschreibt in Alltagssprache, wann ein Bot
handeln darf. Beide können spätere [Anfragen](/de/requests) beeinflussen.

## Eine Entscheidung behalten

Wähle bei der Antwort den gewünschten Umfang. Eine Chat-Freigabe gilt in diesem
Chat. Eine dauerhafte Freigabe bleibt bis zum Widerruf. Schreibe eine Regel,
wenn spätere Arbeit nach einer Bedingung beurteilt werden soll. Nenne Handlung,
Ziel und Bedingung klar.

## Gespeicherte Entscheidungen prüfen

Lies im Client die Regeln und Freigaben, die du verwalten darfst. Widerrufe eine
nicht mehr gewünschte Freigabe. Ändere oder lösche Regeln bei neuen Aufgaben.
Sie geben keine Rechte über deinen Organisationszugriff hinaus.

## Wenn weiter Anfragen kommen

Eine Regel braucht ein Prüfmodel, das die Verwaltung einrichtet. Kann es nicht
entscheiden, entscheidet ein Bot oder Mensch. Eine gespeicherte Wahl passt auch
nicht zwingend zur neuen Handlung oder zum neuen Ziel. Lies die Anfrage, bevor
du eine Regel weiter fasst.
