Gib einem Bot eine Datei, wenn die Aufgabe ein Dokument oder Bild braucht. Die
Plattform braucht Dateispeicher. Dein Client muss Uploads unterstützen.

## Eine Datei an einen Bot geben

Lade die Datei im Client hoch. Warte, bis sie bereit ist. Hänge sie dann an eine
Nachricht und nenne die Aufgabe. Der Upload allein sendet sie nicht an einen
Bot. Das gewählte Model muss diese Eingabeart unterstützen.

## Eine Datei behalten oder löschen

Du kannst eigene Dateien lesen und löschen. Ein Chat mit einem Verweis hält die
Datei. Nach dem Löschen des Chats kann eine ungenutzte Datei entfernt werden.
Meist verfallen ungenutzte Dateien nach 24 Stunden. Die Plattform kann eine
andere Zeit setzen. Behalte eine weitere Kopie wichtiger Dateien.

Gelöschte Dateien sind auch in früheren Nachrichten nicht mehr lesbar. Der Bot
sieht dann einen kurzen Hinweis statt des Inhalts.

OpenBot speichert den Löschauftrag in derselben Datenbanktransaktion, die die
Datei verbirgt. Ein gemeinsamer Workflow entfernt erst die Bytes, dann den
Dateidatensatz. Ein Speicherfehler hat eine gespeicherte Fehler-ID. Ein neuer
Versuch folgt nach einer wachsenden Wartezeit. Ein Neustart behält den Auftrag
und seine Ergebnisse. Eine dauerhafte Aufgabe sucht alte, ungenutzte Dateien;
die Instanzen haben keine eigenen Löschschleifen.

Die Datenmigration hält einen alten, offenen Löschauftrag als unterbrochene
Arbeit fest. Sende eine neue Löschanfrage, um ihn mit deinen aktuellen Rechten
fortzusetzen. Wiederholte Anfragen nutzen die aktive Aufgabe. Bei einem
unbekannten externen Ergebnis bleibt die Aufgabe bis zur Entscheidung gestoppt.

## Ein Upload-Problem lösen

Prüfe Dateityp, Größe und Speichergrenze. Eine Datei im Upload ist noch nicht
für eine Nachricht bereit. Bei fehlendem Speicher oder Upload wende dich mit dem
Fehler an die Verwaltung oder den Client-Anbieter.

## Erzeugte Ergebnisse lesen

Dateien, die ein Bot als [Artefakte](/de/artifacts) veröffentlicht, behalten
eine feste Ergebnis-ID und feste Versionen. Wer ihren Chat lesen darf, kann sie
herunterladen. Normale Uploads behalten ihren privaten Zugriff.
