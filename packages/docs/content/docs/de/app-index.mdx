Der App Index ist eine öffentliche Liste von Apps. Du kannst ohne Anmeldung
suchen. Dein Client kann den OpenBot-Index oder einen anderen Indexdienst
nutzen.

## Suchen und prüfen

Suche nach Aufgabe oder App-Name. Lies Beschreibung, Herausgeber und
Quelladresse. Ergebnisse können unvollständig sein, wenn ein externer Index
nicht erreichbar ist. Versuche es später erneut, wenn eine erwartete Quelle
fehlt.

## Ein Ergebnis verbinden

Wähle die gewünschte App und folge [Apps verbinden und nutzen](/de/apps). Ein
Suchergebnis ist noch keine Verbindung oder Freigabe. Prüfe den Dienst und melde
dich bei Bedarf an.

## Wenn eine App fehlt

Der Herausgeber hat vielleicht keinen Indexeintrag beantragt oder ihn
zurückgezogen. Auch der Host kann ihn beschränken. Eine private manuelle
Verbindung erscheint nicht im öffentlichen Index. Frage den App-Anbieter nach
der Adresse oder die Verwaltung nach der Verfügbarkeit.

## Gespeicherte öffentliche Prüfungen

Eine öffentliche Prüfung hat eine gemeinsame Ausführung. PostgreSQL speichert
jedes Ergebnis. Ein gespeicherter Timer startet die nächste Prüfung. Ein Befehl
kann sie früher anfordern. Mehrere Anfragen können dieselbe offene Prüfung
nutzen. Ein Neustart behält den gespeicherten Fortschritt.

Bei einem kurzen Netzwerkfehler bleibt der letzte bestätigte Eintrag bestehen.
Eine weitere Prüfung folgt. Ein bestätigter Rückzug, `noindex` oder ein Verbot
durch robots entfernt den Eintrag. Private App-Verbindungen bleiben bestehen.
Eine Plattformbeschränkung sperrt die Nutzung weiterhin.

Die Datenmigration behält alte Einträge, Prüfergebnisse und den nächsten
Prüftermin. Jeder alte Indexauftrag erhält eine gemeinsame Plattformausführung.
Eine offene öffentliche Leseanfrage kann nach dem Start erneut laufen. Die
Migration selbst sendet keine Netzwerkanfrage.
