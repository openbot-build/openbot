In Code Mode ruft ein Bot App-Werkzeuge mit einem kurzen Programm auf und
verarbeitet ihre Ergebnisse. Der Plattformbetrieb muss dies einschalten. Du
musst das Programm nicht selbst schreiben.

## Die Aufgabe stellen

Verbinde die nötigen [Apps](/de/apps) und nenne das gewünschte Ergebnis. Der Bot
kann ein Programm für mehrere Aufrufe oder große Ergebnisse wählen. Jeder Aufruf
durchläuft weiterhin die normalen Zugriffsprüfungen.

## Eine Entscheidung prüfen

Eine Anfrage kann das Programm und den betroffenen App-Aufruf zeigen. Prüfe
Handlung und Werte. Mehrere Aufrufe geben dem Programm keine weiteren Rechte.
[Vault](/de/vaults)-Verweise behalten ihre Grenzen.

## Das Ergebnis prüfen

Ein Programm kann laufen, auf eine Entscheidung warten, fertig, fehlgeschlagen
oder abgebrochen sein. Spätere Ergebnisse kommen in den Chat. Eine geänderte
Verbindung kann das Programm nach dem Warten stoppen. Prüfe gespeicherte Aufrufe
vor einem neuen Start, besonders wenn eine App schon Daten geändert haben
könnte.

Ein Upgrade behält gespeicherte Ergebnisse. Alte Arbeit, die nicht sicher
weiterlaufen kann, wird als unterbrochen markiert. Das Lesen ihres Verlaufs
startet sie nicht erneut.
