Ein Chat ist dein Gespräch mit einem Bot. OpenBot behält einen direkten Chat für
dich und jeden Bot. Dein Client zeigt Nachrichten und Arbeit darin.

## Arbeit geben und lenken

Nenne das gewünschte Ergebnis und die nötigen Angaben. Füge bei Bedarf
[Dateien](/de/files) hinzu. Ein Arbeitsabschnitt heißt Turn. Eine weitere
Nachricht desselben Autors kann den laufenden Turn lenken. In einer Gruppe
wartet eine andere Person gegebenenfalls auf ihren eigenen Turn.

Nutze den Planmodus, wenn du zuerst einen Plan möchtest. Prüfe, ob der Plan eine
Freigabe braucht. Eine Aufgabenliste zeigt Schritte, beweist aber keinen
Abschluss. Der Bot kann auch eine Erinnerung setzen, um später zur Aufgabe
zurückzukehren.

## Das Ergebnis lesen

Der Client kann einen Stream oder eine fertige Antwort zeigen. Lange
[Delegationen](/de/delegation), [Anfragen](/de/requests) und Erinnerungen können
später weitere Nachrichten bringen. Prüfe neben der letzten Antwort auch offene
Arbeit. Das Schließen eines Streams stoppt die Arbeit nicht.

Lange Gespräche können für das Model zusammengefasst werden. Gib wichtige
Angaben erneut, wenn der Bot sie braucht.

## Arbeit stoppen oder löschen

Unterbrich einen laufenden Turn im Client, wenn er stoppen soll. Prüfe auch
getrennte Hintergrundarbeit. Das Stoppen nimmt bereits ausgeführte
App-Handlungen nicht zurück.

Das Löschen des Verlaufs entfernt den Chat-Verlauf, aber nicht das
[Bot-Gedächtnis](/de/memory). Dateien, die nur dieser Chat hält, können später
verschwinden. Lies bei einem fehlgeschlagenen Turn den Fehler, bevor du dieselbe
Aufgabe erneut sendest.
