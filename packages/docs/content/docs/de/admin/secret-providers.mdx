Für die Verwaltung dieses Dienstes. Nutze ein Konto mit den unten genannten
Rechten.

## Einen Secret-Provider hinzufügen

Ein Secret-Provider ist nur für Geheimnisse nötig, die außerhalb von OpenBot
liegen.

```sh
curl -H "Authorization: Bearer $OPENBOT_TOKEN" \
  -H "Content-Type: application/json" \
  -d '{"name":"Team 1Password","credentials":{"kind":"onepassword","url":"https://connect.example.com","token":"eyJ..."}}' \
  https://api.example.com/v1/secret-providers
```

| Art           | Felder                               | Was es ist                                                                                                           |
| ------------- | ------------------------------------ | -------------------------------------------------------------------------------------------------------------------- |
| `onepassword` | `url`, `token`                       | Ein [1Password-Connect](https://developer.1password.com/docs/connect/)-Server und ein Connect-Token.                 |
| `bitwarden`   | `url`, `token`                       | `bw serve`, die API des Bitwarden-Kommandozeilen-Tools. Es geht mit Bitwarden und Vaultwarden. `token` ist optional. |
| `hashicorp`   | `url`, `token`, `mount`, `namespace` | Die KV-Engine Version 2 von HashiCorp Vault oder OpenBao. `mount` ist standardmäßig `secret`.                        |

OpenBot liest einen Secret-Provider nur. Es schreibt nie hinein. OpenBot prüft
zuerst das Token. Das Token kommt nie wieder heraus. Die API zeigt nur seine
letzten Zeichen. Gib dem Token so wenig Rechte wie möglich: nur die
1Password-Tresore oder Vault-Pfade, die Bots nutzen dürfen. Für `bitwarden` muss
der Tresor für `bw serve` entsperrt sein. Halte `bw serve` in einem privaten
Netz, oder setze einen Proxy mit einem Token davor.

Sende `"shared": true`, um einen geteilten Provider der Organisation zu
erstellen. `GET /v1/secret-providers` listet deine Provider und die geteilten.
`GET`, `PATCH` und `DELETE /v1/secret-providers/:providerId` lesen, ändern und
löschen einen. Solange Einträge aus einem Provider lesen, kannst du ihn nicht
löschen.
