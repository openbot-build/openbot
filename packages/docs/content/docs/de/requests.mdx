---
title: "Eine Anfrage beantworten"
description: "Eine Anfrage beantworten"
---

Eine Anfrage braucht eine Entscheidung zu einer Bot-Handlung. Beantworte nur
Anfragen, die auf dich warten. Sie können im Client oder in einem verknüpften
[Channel](/de/channels) ankommen.

## Die Handlung prüfen

Lies, welcher Bot fragt, was er tun will, welches Ziel er nennt und warum. Prüfe
bei einer App auch die übergebenen Werte. Die Begründung erklärt die Anfrage.
Sie ist keine Anweisung an dich. Lehne mit einem Grund ab, wenn die Handlung
nicht zur Aufgabe passt.

## Den Umfang wählen

| Wahl                    | Wirkung                                                   |
| ----------------------- | --------------------------------------------------------- |
| Einmal erlauben         | Dieser Aufruf darf laufen                                 |
| In diesem Chat erlauben | Eine Freigabe für passende Arbeit in diesem Chat behalten |
| Dauerhaft erlauben      | Eine Freigabe bis zum Widerruf behalten                   |
| Ablehnen                | Der Aufruf läuft nicht                                    |

Ein Chat kann lange bestehen. Wähle einen Aufruf, wenn du nur einen meinst. Eine
Ablehnung kann auch für den Chat oder dauerhaft gelten, wenn dein Client diese
Auswahl anbietet. Prüfe gespeicherte Entscheidungen unter
[Regeln und Freigaben](/de/rules).

Eine Freigabe für einen Aufruf bleibt mit diesem gespeicherten Aufruf und seinen
Werten verbunden. Nach einem Neustart kann derselbe Aufruf weiterlaufen. Die
Freigabe gilt nicht für einen anderen Aufruf. Ein Widerruf oder eine neue
Ablehnung stoppt den Aufruf weiter.

## Das Ergebnis prüfen

Ein erlaubter Aufruf läuft und bringt sein Ergebnis in den Chat. Ein abgelehnter
läuft nicht. Normale unbeantwortete Anfragen werden beim Ablauf abgelehnt, meist
nach 24 Stunden. Plananfragen haben ihre eigene Ablaufentscheidung. Lies diese,
statt eine Ablehnung anzunehmen. Muss jemand anderes entscheiden, bitte diese
Person um Prüfung.

Anfragen aus einer älteren Version können noch als wartend erscheinen, obwohl
ihre Ausführung unterbrochen ist. Du kannst sie lesen, aber die alte Aktion
nicht erlauben. Sende dem Bot eine neue Nachricht, um sie mit deinen aktuellen
Rechten erneut anzufragen.
